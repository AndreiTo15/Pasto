# Pasto

1. Crea un repository GitHub (es. `pasto`) e carica TUTTI i file di questa cartella nella root (incluso `.nojekyll`).
2. Settings > Pages > Deploy from a branch > `main` / `(root)` > Save.
3. Apri l'indirizzo `https://TUO-UTENTE.github.io/pasto/` in Safari su iPhone.
4. Condividi > Aggiungi alla schermata Home.

I dati (peso, spunte) sono salvati nel browser e NON passano dalla versione di Claude a quella su GitHub:
usa Peso > Backup dati > Copia backup, poi Ripristina nella nuova app.

Per cambiare il piano, modifica l'array `D` dentro `index.html`.
